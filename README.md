# Portfolio Management System

This project implements a backend system for managing financial advisors, clients, portfolios, and securities using Spring Boot and JPA.

## Features
- Financial advisors can manage multiple clients
- Each client has a portfolio
- Portfolios contain multiple securities
- CRUD operations supported via JPA

## Data Model
Entities:
- FinancialAdvisor
- Client
- Portfolio
- Security

## Tech Stack
- Java
- Spring Boot
- JPA (Hibernate)
- H2 Database

## How to Run
1. Clone the repo
2. Run using:
   mvn spring-boot:run
